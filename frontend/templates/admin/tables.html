How the tables relate

users ──< user_sessions            (one user, many logins)
users ──< cart ──< cart_items >── products
categories ──< products
cart ──── orders ──< order_items >── products     (orders.cart_id is UNIQUE)
orders ──── payments                              (payments.order_id is UNIQUE)

──< means "has many";  PK = primary key, FK = foreign key.

Checkout runs as one SQL transaction: validate stock → create order → copy items → reduce stock → create payment → close cart → COMMIT (or ROLLBACK on any error).
